# План адресации

Единый план IP-адресов для всех топологий репозитория. Топологии не пересекаются по адресам,
поэтому их можно собирать независимо или объединять.

## Принципы

- Пользовательские сети — из `192.168.0.0/16`, по одной `/24` на сегмент (`192.168.<номер сегмента>.0/24`).
- Транзитные каналы «точка–точка» — `/30` из `10.0.0.0/8` (два адреса хоста, без потерь).
- Шлюз сети — первый адрес диапазона (`.1`). Для HSRP `.1` — виртуальный, реальные адреса — `.2`, `.3`.
- Адреса «внешнего мира» — только из зарезервированных диапазонов или явно помеченные имитации (Loopback).

## Топология 1 (`topologies/topology1.md`)

| Сеть | Назначение |
|------|-----------|
| 192.168.1.0/24 | LAN за R1 |
| 192.168.2.0/24 | LAN за R2 |
| 10.0.0.0/30 | линк R1 — R2 (OSPF area 0) |

## Топология 2 (`topologies/topology2.md`)

| Сеть | Назначение |
|------|-----------|
| 192.168.10.0/24 | LAN1 за R1 |
| 192.168.30.0/24 | LAN3 за R3 |
| 10.1.12.0/30 | линк R1 — R2 |
| 10.1.23.0/30 | линк R2 — R3 |

## Топология 3 (`topologies/topology3.md`)

| Сеть | Назначение |
|------|-----------|
| 192.168.10.0/24 | LAN, виртуальный шлюз HSRP 192.168.10.1 |
| 10.2.1.0/30 | линк R1 — R3 |
| 10.2.2.0/30 | линк R2 — R3 |
| 1.1.1.1/32 | Loopback на R3 (имитация внешнего узла) |

> Топологии 2 и 3 используют одну и ту же пользовательскую сеть `192.168.10.0/24`.
> Если собираете их в одном проекте Packet Tracer, смените адресацию одной из них.

## Проверка плана

Перед настройкой оборудования сверьтесь с калькулятором из `netadmin-subnetting-vlsm-labs`:
```bash
python scripts/subnet_calculator.py 10.1.12.0/30
```
